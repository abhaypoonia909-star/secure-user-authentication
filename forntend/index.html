What's built in

Everything the sign-in surface needs

The parts users touch are done: real validation, honest error messages, and states for every outcome your backend can return.

Strong passwords, enforced

A live strength meter scores length, case, digits, and symbols before the form will submit.

Server-side sessions

No tokens in browser storage. The dashboard is guarded by a signed, HttpOnly cookie your server sets.

Rate-limit feedback

Repeated failures surface a cooldown notice instead of a silent retry loop, so people know what to do next.

Email verification flow

Register hands off to a "check your inbox" state, ready to point at your confirmation route.

Activity you can read

The dashboard lists recent sign-ins with device and location, so a stranger's session stands out.

Responsive to the last breakpoint

The split auth layout folds to a single column on phones without losing the brand panel.

Backend ready

Wire it to Flask in an afternoon

Each form posts to a named route with predictable field names. Swap the placeholder action for url_for(), drop in a CSRF token, and the front end is done.

  • POST /register full_name, email, password
  • POST /login email, password, remember
  • GET /dashboard login required
  • POST /logout clears the session
  • POST /forgot-password sends a reset link
